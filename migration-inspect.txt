# Level Up: Interview Arena

Interactive Level Up learning module for interview preparation, practice, reflection, and coach-ready review.

The production site is served from `dist/`. Progress is synchronized with the shared Level Up Supabase project under the module key `interview-arena` when a participant has an active Level Up session.

## GitHub Pages

The included Pages workflow publishes `dist/` whenever `main` is updated.
